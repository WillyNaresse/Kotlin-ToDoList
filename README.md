# Kotlin-ToDoList

## Descrição
Aplicação Android desenvolvida com Jetpack Compose que implementa autenticação de usuários e persistência de tarefas na nuvem utilizando Firebase.

## Funcionalidades
- Cadastro e login de usuários (Firebase Authentication)
- Persistência de tarefas por usuário (Firebase Firestore)
- Criação, edição e remoção de tarefas
- Recuperação automática das tarefas após login

## Tecnologias Utilizadas
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore
- Arquitetura MVVM

## Arquitetura
O projeto segue o padrão MVVM, separando UI, lógica de negócio e acesso a dados, garantindo organização, testabilidade e manutenção.

## Estrutura do Projeto
- UI/: telas e componentes Compose
- viewmodel/: gerenciamento de estado
- repository/: acesso ao Firebase

## Execução
1. Clonar o repositório
2. Abrir no Android Studio
3. Configurar o Firebase
4. Executar no emulador ou dispositivo físico
